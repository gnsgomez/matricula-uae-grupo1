# Sistema de Matrícula UAE

## Descripción del Proyecto
El Sistema de Matrícula UAE es una plataforma web diseñada para optimizar el proceso de inscripción de estudiantes en la Universidad Agraria del Ecuador. Este sistema permite a los estudiantes visualizar la oferta académica, seleccionar sus materias y gestionar su carga horaria de manera eficiente, reduciendo los tiempos de espera y minimizando errores en el proceso de matrícula.

El sistema está pensado para facilitar la experiencia del estudiante, ofreciendo una interfaz intuitiva que muestra información actualizada sobre cupos disponibles, horarios y requisitos previos para cada asignatura.

## Funcionalidades Principales
- **Inicio de sesión**: Autenticación con credenciales institucionales (cédula y contraseña)
- **Visualización de materias**: Listado completo de asignaturas del semestre con detalles de horarios
- **Consulta de cupos**: Visualización en tiempo real de cupos disponibles por paralelo
- **Selección de materias**: Sistema para elegir asignaturas y gestionar la carga académica
- **Confirmación de matrícula**: Proceso final para formalizar la inscripción
